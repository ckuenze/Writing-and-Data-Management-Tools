# Writing and Data Management Tools

Browser-based tools for common research writing and data management tasks: building reporting figures, organizing study data, and preparing material for submission.

Each tool is a single HTML file that runs in a modern web browser, with nothing to install. Everything runs locally, so no data leave your computer.

## Tools

| Tool | Purpose |
|---|---|
| [CONSORT Flow Diagram Builder](consort-flow-builder/) | Build participant flow diagrams (CONSORT, STROBE-style) at print size, check that counts add up, and export SVG, PDF, or high-resolution PNG |

## How to open a tool

1. Click a tool's folder above.
2. Download `index.html` (click the file, then the download button).
3. Open the file in Chrome, Edge, Firefox, or Safari.
